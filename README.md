# Лабораторная работа № 1 — вариант 10

Программа на Scala ищет временные файлы и папки по заданным правилам. Выбранные объекты перемещаются в карантин после подтверждения. Их можно восстановить или удалить окончательно после окончания срока хранения.

## Подготовка к запуску

1. Скачайте репозиторий и распакуйте его или клонируйте через Git.
2. Откройте папку проекта в IntelliJ IDEA. Это папка, в которой лежат `build.sbt` и `config.properties`.
3. Убедитесь, что установлен плагин Scala и выбран JDK. Дождитесь загрузки зависимостей sbt.
4. В корне проекта создайте папку `data`, а внутри неё — пустую папку `quarantine`.

Должна получиться такая структура:

```text
папка проекта/
  build.sbt
  config.properties
  data/
    quarantine/
  demo/
  project/
  src/
```

Папку `data/quarantine` нужно создать вручную: Git не сохраняет пустые папки, а `data` исключена из репозитория. Не добавляйте в карантин `.gitkeep` или другие посторонние файлы. Если папки нет, программа сообщает: «Каталог карантина отсутствует».

В проекте используются Scala 3.3.6 и sbt 1.10.7. Версии уже указаны в настройках проекта.

## Запуск в IntelliJ IDEA

1. Откройте `src/main/scala/cleaner/Main.scala`.
2. Запустите метод `main` зелёной кнопкой рядом с ним.
3. Если программа не находит `config.properties`, проверьте рабочую папку в настройках запуска. Она должна указывать на корень проекта, где лежит этот файл.

## Как проверить программу

В репозитории есть учебная папка `demo`. Для первой проверки можно использовать её.

1. В главном меню откройте «Поиск и результаты».
2. Выберите «Начать поиск».
3. На вопрос о точках поиска введите `all`.
4. На вопрос о профиле введите `full`.
5. Просмотрите результаты. Через «Подробнее об объекте» можно узнать причину выбора.
6. В пункте «Выбрать объекты» введите `all` или выберите нужные номера через `ids`.
7. Выберите «Поместить выбранные объекты в карантин». Нажмите Enter, чтобы оставить срок хранения из настроек. Для подтверждения введите `ДА` заглавными русскими буквами.
8. Чтобы вернуть объект, откройте меню «Карантин» и выберите «Восстановить объект». Введите полный номер записи из списка карантина.

При свежем скачивании временные файлы могут ещё не подходить по возрасту: для `notes.tmp` нужно не меньше 24 часов, для `video.part` — 72 часов. Git не сохраняет исходные даты изменения файлов. Каталог `demo/sample/target` подходит по наличию файла проекта `build.sbt` рядом с ним.

`0` возвращает в предыдущее меню, а в главном меню завершает программу.

## Настройки и сохранение данных

Настройки находятся в `config.properties`. Точки поиска можно менять через меню. После ручного изменения конфигурации используйте пункт «Перезагрузить настройки».

Карантин и точки поиска должны находиться на одном диске: перенос между дисками в этой версии не поддерживается.

История, журнал, отчёт и состояние карантина создаются в папке `data` по мере работы. Не удаляйте эту папку, пока в карантине есть нужные данные: для восстановления нужны и сами объекты, и файл состояния.

Окончательное удаление выполняется только после истечения срока хранения и отдельного подтверждения. Восстановление возможно, пока объект фактически не удалён.
